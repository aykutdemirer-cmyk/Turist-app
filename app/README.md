# @localbite/app

LocalBite mobil uygulaması: Expo SDK 57 + Expo Router. Harita `react-native-webview` içinde Leaflet +
OpenStreetMap ile çizilir; yemek adlarının sesli telaffuzu `expo-speech` ile yapılır.

Kurulum, ortam değişkenleri (`EXPO_PUBLIC_API_URL` vb.), komutlar ve özellik listesi için kök
[README.md](../README.md) dosyasına bakın.

Hızlı başlangıç (API `http://localhost:3001` üzerinde çalışırken):

```bash
npx expo start          # bu klasörde; Expo Go ya da emülatör
npm run typecheck && npm run lint && npm test
```
